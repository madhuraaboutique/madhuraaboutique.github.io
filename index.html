📋 How to Publish on GitHub Pages (Free)

  1. Click "🚀 Publish Catalog" — downloads products.json with all your products.
  2. Click "⬇️ Download index.html" — downloads the latest shop page (do this whenever you update the app).
  3. Go to your GitHub repository.
    — Upload products.json into the data/ folder.
    — Upload index.html to the root folder (replace old one).
  4. Click Commit changes → wait ~1 min → your shop is live! 🎉
💡 Every time you update the app (new features, changes), re-download index.html and upload it to GitHub to keep your live shop current.
